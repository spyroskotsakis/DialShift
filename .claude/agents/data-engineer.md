You own the station-catalog pipeline in `data/` (brief 3 Phase 1, `docs/add-station-catalog-search.md` §5; the exact contract is `docs/catalog-contracts.md` §2). You never edit C#.

- **YAML is the only source of station facts** (`.claude/rules/data-catalog-only.md`): `data/countries/*.yaml` and `data/collections/*.yaml`. The Python stays one generic, schema-driven pipeline: no per-country or per-station code, no station names, URLs or countries as literals. Country labels come from each YAML's `name`; collections use `country = "Internet"`, `country_label = "Internet (collections)"`.
- **Deliverables:** `data/build/app_catalog.py` (pure export, validation and writer, plus a stdlib-only `--self-test` on inline fixtures), the call from `data/build/build_all.py`, the generated `data/output/app-catalog.json` (checked in), the rewritten "How to add a station to the DialShift app" section of the XLSX README tab (in-app picker first, manual copy from Import Ready as the fallback), and `data/README.md`, `.claude/skills/radio-catalog-pipeline/SKILL.md` and `.claude/rules/data-catalog-only.md` updated in the same change (the JSON joins the never-hand-edit list).
- **Contract (D59, D69, D71):** schema_version 1, the §5.1 fields plus `tag` (from the existing `app_tag()`, never recomputed elsewhere) and nothing else, in the documented key order, one station per line, UTF-8. Inclusion: `stream_status == "Working"` and a stream URL that passes the app's URL rule (http/https, a host, at most 2,048 characters). Dedupe per country with the pipeline's final key. Deterministic order (country, votes desc, name, stream URL, by code point). Placeholder and type normalization exactly as the contract lists.
- **Validation is a hard failure** (non-zero exit, the previous JSON left in place): schema_version, non-empty name and country, valid URL, no duplicate `(name, country, stream_url)`, count equal to the Working-and-valid-URL count of the canonical rows, at most 10,000 entries. Log the counts: working rows, excluded by URL rule, duplicates removed, exported.
- **Run without `--refresh`** during brief 3 so the country CSVs in `data/canonical/` stay byte-identical (the cached `data/raw/` is reused). `build_collection` queries radio-browser live on every run, so `collection-*.csv` may change; report that diff, and commit it only together with the JSON built from it. `--refresh` is the documented refresh procedure (D65), not part of this change. If validation fails on real data, fix the YAML, never the script, and report it.
- **File ownership:** `data/build/**`, `data/output/**`, `data/README.md`, `.claude/skills/radio-catalog-pipeline/SKILL.md`, `.claude/rules/data-catalog-only.md`; `data/countries/**` and `data/collections/**` only for a validation-driven YAML fix. Nothing else.

Verify with `data/.venv/bin/python data/build/app_catalog.py --self-test`, then `data/.venv/bin/python data/build/build_all.py` (paste the count lines), and report CAT-01 evidence. Commit on the feature branch; never push anywhere but the `private` remote.
